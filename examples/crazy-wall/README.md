# Karte Research Wall PoC

PDF・Markdown・画像・音声を，解釈や仮説と並べて検討するローカルのボードです．既存のコルクボードから独立しており，Karteのデータには書き込みません．

## 起動

Node.js 22.13以降を使用します．Karteの`frontend/node_modules`がある環境では，そのPDF.jsを利用できるため追加インストールは不要です．単独で使う場合は，このディレクトリで`npm install`を実行してください．

```sh
npm start
# http://127.0.0.1:4180/
```

`PORT=4181 npm start`でポートを変更できます．サーバーは127.0.0.1だけで待ち受けます．

## 試せる操作

- カードの移動，ボードのパン・ズーム，全体表示，全画面表示．狭い画面では左のライブラリを閉じられます．
- PDF・Markdown・画像・音声のファイル選択とドロップ．PDFはPDF.jsで表示し，ページを切り替えられます．
- 原資料のダブルクリック表示．PDFのページ・音声の時刻・Markdown本文などを参照する抜粋カードの作成．
- 「つなぐ」で始点・終点を順に選択し，支持・矛盾・関連・要確認と判断理由を保存．確認済み／未確認を実線／破線で区別．
- 関係一覧からの見直し，仮説メモの追加，資料の検索・種類フィルター，操作の取り消し．
- IndexedDBへの自動保存．ページ再読込後も原資料を含めて復元．JSONの書出し／読込みで別ブラウザへ持ち運び．

ショートカット：`V`選択，`H`移動，`C`つなぐ，`N`メモ，`F`全体表示，`Space`一時パン，`Esc`解除，`⌘/Ctrl+Z`取り消し．選択カードは矢印キーで移動，Shift併用で大きく移動できます．

## PoCの範囲

- サンプルはすべて架空です．画像はオリジナルのSVGスケッチ，PDFは架空の2ページ調査書です．サンプル音源は合成環境音で，表示された架空の発言は収録していません．波形も装飾です．
- 評価は利用者の判断を記録する仕組みです．OCR，文字起こし，AI推定，Karteの実ファイル一覧・保存・同期には未接続です．
- 1ファイル20MB，取り込む資料本体は合計80MB，Markdownは1MB，カード250枚まで．実際の保存容量はブラウザの空き容量にも依存します．
- Markdownは安全な簡易表示です．生HTML，外部画像，外部リンク，数式，表，埋込みは解釈しません．
- PDFは画像スキャンを表示できますがOCRは行いません．暗号化PDFは未対応です．音声の対応コーデックはブラウザに依存します．
- ブラウザのサイトデータ削除で保存内容が消えます．JSONには取り込んだ資料の本体が含まれます．重要な作業はJSONでも保存してください．
- JSON形式は`karte-research-wall/1`です．既存の`.board.md`との互換性はまだありません．

## 組込み時の分担案

既存の`internal/board`のCard / Edge / Layoutへ移す際は，PDFページや音声時刻を`Card.Meta`へ，判断理由を`Edge.Description`へ対応付けられます．確認状態はEdgeに追加の永続化が必要です．資料本体をボードへ埋め込むPoC形式から，Karteが管理する安定した資料IDと相対パスに置き換える想定です．

表示・座標変換・メディアプレビューはDOMに依存する表示層として分離し，ファイル選択・保存・元資料の解決はKarte側のアダプターに寄せます．共通のボードデータと参照箇所のモデルを先に定めれば，Karte_rendererのCLIはGUIなしでレイアウト・関係・抜粋を読むことができます．今回のPoCにはCLIからのレンダリングは含めていません．

## 検証

```sh
npm test
```

モデルの読込み検証，関係の重複防止，接続座標，表示範囲，MarkdownのHTML無効化を確認します．PDF・音声・ファイル選択・復元はブラウザでも操作確認します．
