Graph Module Test (D3.js)

使用方法: ボタンをクリックしてグラフの様々な機能をテストできます。 ノードやエッジにマウスをホバーすると詳細情報がツールチップで表示されます。 ノードをクリックすると詳細情報がアラートで表示されます。
新機能 (D3.js): D3.jsのフォースシミュレーションを使用してリアルタイムの物理演算を行います。 ノードをドラッグすると、リアルタイムで斥力が計算され、他のノードとの距離が保たれます。
注意: このファイルはローカルサーバーで実行する必要があります。 python -m http.server 8001 または npx serve . を使用してください。
